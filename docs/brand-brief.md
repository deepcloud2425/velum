# Velum — Brand Identity & Visual Design Brief

## 1. Brand Essence & Vision

**Velum** is the premier confidentiality layer for decentralized commerce on the **Midnight Network**. We believe privacy is not secrecy—it is the fundamental prerequisite for financial sovereignty, commercial security, and human dignity in the digital age.

Velum bridges zero-knowledge mathematical privacy (Compact smart contracts + Groth16 zk-SNARKs) with enterprise-grade regulatory auditability.

---

## 2. Core Brand Attributes

- **Sovereign & Confidential**: Transactions shield senders, receivers, and amounts from public block explorers.
- **Mathematically Verifiable**: No trusted parties. Cryptographic proofs verify value conservation ($input = output + change$) and prevent double-spending off-chain.
- **Regulatory Ready**: Programmable selective viewing keys enable compliance and tax reporting without surrendering spend authority.
- **Architecturally Native**: Built directly for Midnight Preprod and the 1AM Wallet DApp Connector.

---

## 3. Visual Identity & Color System

| Role | Color Name | Hex Code | Purpose & Application |
|---|---|---|---|
| **Deep Space** | Midnight Black | `#09090B` / `#000000` | Background, primary text, bedrock container contrast |
| **Accent Glow** | Velum Electric Cyan | `#06B6D4` / `#6366F1` | Primary buttons, active state indicators, high-contrast badges |
| **Proof Verified** | ZK Emerald | `#10B981` | Cryptographic proof success, verified ledger state |
| **Pending Ping** | Amber Warning | `#F59E0B` | Wallet authorization awaiting, proof generation |
| **Surface Bedrock** | Pure White / Clean Slate | `#FFFFFF` / `#F8FAFC` | Card surfaces, interactive elements |
| **Border / Rule** | Titanium Zinc | `#E4E4E7` / `#D4D4D8` | Precision wireframes, dividers, technical badges |

---

## 4. Typography & Layout Principles

- **Wordmark & Headings**: Bold, geometric sans-serif (Inter / Geist / Space Grotesk). High contrast, assertive, modern.
- **Data & Crypto Displays**: Monospace (JetBrains Mono / SF Mono). Addresses, hashes, commitments, and mathematical proofs are treated as first-class architectural elements.
- **Micro-interactions**: Crisp 150ms spring animations via Framer Motion, precise hairline borders (1px), subtle elevation.
